# Esquemas de particionado
## MBR (Master Boot Recoberi)
- Máximo 4 particiones : 3 normales + 1 extendido
- Si el MBR se daña, el disco puede quedar inaccesible.
- Tabla de particiones al inicio del disco. Está duplicado, pero igualmente al inicio.
- Muy simple y ampliamente soportado.
- No tiene mucha tolerancia a errores.

## GPT (GUID Partition Table)
- Moderno
- Usa UEFI
- Hasta 128 particiones posibles (7bits).
- Copia de seguridad de la tabla de particiones al principio y final del disco.
- Verificación de integridad madiante **CRC** : Cödigo de Redundancia Cíclica

# Sistemas de archivos
## Windows
### FAT32
- Limita de archivo de 4GB
- Sin permisos ni journaling.
	- Escritura de morada : registro de los archivos que se está manejando.
- Altísima compatibilidad.
- Sistema muy antiguo.
- Dispositivos compatibles entre dispositivos.

### exFAT
- Menos seguro que NTFS




### NTFS
- Sistema estándar de Windows.
- Journaling y control de archivos.
- Soporta permisos y cifrado.
	- Va más lento porque constantemente tiene que cifrar y descifrar si se activa.

## Linux
### ext2
- Sistemas embevidos : sistemas incrustrados ( embeded ).

### ext3

### ext4
- Estable y fiable
- Sin snapshots nativas (instantaneas)



### XFS
- Alto rendimiento
- Optimizado para archivos grandes (bases de datos, servidores multimedia donde alojas pelis)
- Servidores
- Excelente rendimiento.


### Btrfs
- Sistema muy moderno
- Integridad con RAID software
- Copy-on-Write


### ZFS (no nativo del kernel)
- Hay que añadirlo después
- Sistemas de almacenamieto masivo
- Integridad de datos mediante checksums
- Sistemas de archivos y gestor de volúmenes.
- Altísima fiabilidad
- Alto consumo de memoria.
